# AI Slop Integrator: A Viaticum for my art, and my career

This project presents a mindless foray into the world of AI code and Spec
Driven Development. For too long have I wallowed in this miserable profession,
and it is with the publication of this project that I openly show my disdain
for all that I once thought I was worth.

This project is an experiment to use a wretched thinking machine to write code
for something I've always wanted to make, a cart and pole simulator.

Like a cockroach at the butcher's I've siphoned the metaphorical floor for the
stinking detritus of spec driven devlopment from microsoft and amazon repos.
Being too lazy to use Kiro, and too self-respecting to make it a full skill,
I've shoved it into AGENTS.md.

I've left the specs and tasks and all that jazz in place as markdown files so
that my work may be justly despised as time goes on.

## The Project

Like most things I work on, I'm doing this to learn. The goal was to make a
dynamical systems simulator using
[RK4](https://en.wikipedia.org/wiki/Runge%E2%80%93Kutta_methods), but I've
always been too lazy to do it myself. Specifically, I wanted to make a cart
and pole simulator that I could push around. Years ago I wanted to integrate
learned policies with ML. Alas, LLM's are the cool thing now, and I hate them,
so whatever.

This project should eventually compile down into wasm and run in a web browser.
It is written in rust because I like rust. It will be compiled into wasm
because I like wasm.
